# v0.5.0

首个正式公开版，由 `v0.5.0-d-candidate.1` 原样晋级。

## 功能

- 对所有片手剑生效，不依赖武器或防具外观。
- 覆盖 39 个片手 Bank100 动作的空击与命中特效。
- 飞影 `24020/30020` 已完成空击、命中实机验证。
- 持续效果使用实例生命周期管理；实机累计创建 21 次、释放 21 次、失败 0、残留 0。
- 一次性效果与持续效果均为本地视觉，不发送网络特效。
- 包含事务安装、冲突拒绝、哈希校验、回滚和手动文件清单。

## 正式版冻结

- 正式版运行时、39 条配方和 84 个资源与已验收候选保持一致，不引入新的行为改动。
- 已通过 39/39 配方审计、确定性构建、安装与回滚、冲突拒绝及载荷篡改测试。
- 已完成飞影空击/命中、升龙与下坠生命周期实机验证，以及 6 分钟稳定观测。
- 30 分钟连续狩猎仍作为后续增强回归，不冒充本版已完成证据。
