# 人工验收清单

## 核心原型

- [ ] 普通连段焰轨细窄，角色与怪物轮廓清晰。
- [ ] 连段终结具有白金焰芯与短促爆燃，不持续遮挡画面。
- [ ] 风车、灭昇龙和下砸的招牌效果方向明确且彼此可辨。
- [ ] 停止攻击后没有持续粒子残留。
- [ ] 所有片手剑生效，其他武器不受影响。
- [ ] 拔刀、收刀、营地换装、任务重置、猫车、切图和返回村庄正常。

## 增强候选（核心验收后）

- [ ] 普通连斩、盾击和精准突击仅在动作迁移时单次触发。
- [ ] 连续战斗 30 分钟无实例积累、明显掉帧或内存持续增长。
- [ ] 换装、进出任务、猫车、返回村庄及脚本重载均清理实例与缓存。
- [ ] 私人联机房加入、退出和多名猎人攻击时不崩溃、不改变伤害或网络状态。
- [ ] 缺少 REFramework 或 FirstNatives 时说明清楚，不导致游戏启动崩溃。

## 安装与分发

- [ ] Core 可由 Fluffy 安装、禁用和卸载，卸载后恢复原始效果。
- [ ] Core 与 Enhanced 不同时安装。
- [ ] 包内只有 10 个片手 EFX、项目 Lua 和 `modinfo.ini`。
- [ ] 包内没有 DLL、EXE、PAK、个人路径、原始未修改资源或参考 Mod 文件。
