## 记录方法

1. 只改一个 EFX，并使用明显但不刺眼的诊断色。
2. 固定武器、训练场、摄像机和光照，逐一执行片手主要动作与替换技。
3. 同步运行只读动作探针，记录 `node_id`、`node_name` 和命中时刻。
4. 确认触发动作、阶段、挂载位置、持续时间及是否与其他武器共享。
5. 恢复原始文件后再测试下一个 EFX，避免交叉污染。
